      ↓
If key exists → value

|--------------------------------------------------|
| Method / concept | Purpose                       |
| ---------------- | ----------------------------- |
| `server["name"]` | Access a value                |
| `.get()`         | Safely access an optional key |
| `.keys()`        | Get all keys                  |
| `.values()`      | Get all values                |
| `.items()`       | Get key + value               |
| `.update()`      | Add/update values             |
| `.pop()`         | Remove a key/value            |
| `is None`        | Check for missing value       |
